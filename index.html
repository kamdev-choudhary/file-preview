One custom element renders PDFs, Word and PowerPoint documents, spreadsheets, images, video, code and archives — in the browser, with no upload and no server. It works in plain HTML and in every framework, because it is only a custom element.

The same component, inline

Embedded in a page instead of a modal. The toolbar changes to match whatever the active viewer supports — page controls for a PDF, sheet tabs for a workbook, zoom for an image. Each viewer is a separate chunk that arrives only when it is first needed.

What it reads

Type is decided by magic bytes first, extension second, and the server's Content-Type last — so a PNG named .txt still renders as an image. Anything unrecognised gets a download card, never a broken view.

Fidelity is stated honestly: exact means pixel-accurate, text only means the words and tables survive but the formatting does not. For Office files at a public URL, the toolbar can hand off to the Microsoft viewer for a full-fidelity render.

Install

The package is ESM-only and ships its own types.

npm i fileon

Or use it straight from a CDN with no build step at all:

<script type="module" src="https://cdn.jsdelivr.net/npm/fileon/+esm"></script>

<file-preview src="/report.pdf" bordered></file-preview>

Quick start

Importing the package registers <file-preview> and <file-preview-modal>. From there you have two entry points: render inline, or open the full-screen modal. 

import { openPreview, renderPreview } from 'fileon';

// Full-screen modal — pass one file or an array for a gallery.
openPreview('/quarterly-report.pdf');

// Or render into an element you already have.
renderPreview('#viewer', fileFromInput, { bordered: true, minHeight: '520px' });

openPreview returns a handle, so a gallery can be driven from your own UI: 

const gallery = openPreview(files, {
  index: 0,
  onLoad: ({ source, viewer }) => console.log(`${source.name} opened in ${viewer}`),
  onError: ({ error }) => console.warn(error.code, error.message),
  onClose: () => {},
});

gallery.go(2);
gallery.close();

Frameworks

A custom element is just a DOM element, so there is no wrapper package to install. The only thing that differs between frameworks is how you set a property that isn't a string. 

<script type="module">
  import 'fileon';
</script>

<file-preview src="/report.pdf" name="Q3 report.pdf" bordered></file-preview>
import { useEffect, useRef } from 'react';
import 'fileon';

export function Preview({ file }) {
  const ref = useRef(null);

  // `file` accepts a File, Blob, URL or descriptor — assign it as a
  // property, because React would stringify it as an attribute.
  useEffect(() => {
    if (ref.current) ref.current.file = file;
  }, [file]);

  return <file-preview ref={ref} bordered style={{ '--fp-min-height': '520px' }} />;
}

For a click-to-open flow, call openPreview(file) from the handler instead — there is nothing to mount. 

<template>
  <file-preview :src="url" bordered />
</template>

<script setup>
import 'fileon';
defineProps({ url: String });
</script>

Tell the compiler these tags are custom elements:

// vite.config.js
vue({
  template: {
    compilerOptions: { isCustomElement: (tag) => tag.startsWith('file-preview') },
  },
});
<script>
  import 'fileon';
  export let file;

  let el;
  $: if (el) el.file = file;
</script>

<file-preview bind:this={el} bordered></file-preview>
import { CUSTOM_ELEMENTS_SCHEMA, Component } from '@angular/core';
import 'fileon';

@Component({
  selector: 'app-preview',
  standalone: true,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<file-preview [attr.src]="url" bordered></file-preview>`,
})
export class PreviewComponent {
  url = '/report.pdf';
}

What you can pass

Anywhere a file is accepted — openPreview, renderPreview or the .file property — you can pass a URL string, a File, a Blob, an ArrayBuffer, a data URI, or a descriptor object. Arrays become a gallery.

Reach for a descriptor when the URL alone doesn't say enough: a signed link with no extension, or an endpoint that needs credentials. 

openPreview({
  url: 'https://api.example.com/files/8fa21c',
  name: 'Q3 report.xlsx',   // gives the detector an extension to work with
  type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
  headers: { Authorization: `Bearer ${token}` },
  credentials: 'include',
});

Element reference

<file-preview
  src="/file.pdf"

el.source;            // the resolved Source, once loaded

Events

All of them bubble and cross the shadow boundary.

Event detail Fires when
fp-load { source, viewer } A viewer finished rendering
fp-error { source, error } A load or decode failed
fp-change { index, source } The gallery moved to another file
fp-close — The modal closed

Configuration

Call configure() once at startup. Every key is optional.

import { configure } from 'fileon';

configure({
  maxBytes: 100 * 1024 * 1024,   // refuse to buffer anything larger
  maxTextBytes: 5 * 1024 * 1024, // truncate text and code past this
  officeViewer: true,            // allow the "Open in Office viewer" action
  credentials: 'same-origin',
  headers: { 'X-Tenant': 'acme' },
  locale: 'en-GB',
});

pdf.js assets

pdf.js pulls its worker and font data from a version-pinned CDN by default, which needs no setup. If you are offline, self-hosted, or run a strict CSP, point it at local copies instead. This one line works in Vite, webpack 5 and Rollup. 

configure({
  pdfWorkerSrc: new URL('pdfjs-dist/build/pdf.worker.min.mjs', import.meta.url).href,
});

Legacy spreadsheets

.xlsx, .xlsm, .csv and .tsv are parsed natively with no extra dependency. Binary .xls and .ods are a different format; supply SheetJS if you need them. 

configure({
  loaders: { xlsx: () => import('https://cdn.sheetjs.com/xlsx-0.20.3/package/xlsx.mjs') },
});

Error handling

Every failure arrives as a PreviewError with a stable code, so you can branch on the cause instead of matching on message text. The built-in error panel already picks its recovery buttons from the same code.

Code Meaning
CORS The server did not allow this page to read the file
HTTP Non-2xx response; error.status has the code
NETWORK The connection failed mid-transfer
TOO_LARGE Larger than maxBytes
PASSWORD Encrypted PDF, workbook or document
DECODE Corrupt, or not the format it claimed to be
UNSUPPORTED No viewer matched this type
DEPENDENCY A parser chunk could not be loaded
EMPTY There was nothing to show
ABORTED Superseded by another load, or closed 
openPreview(url, {
  onError: ({ error }) => {
    if (error.code === 'CORS') showCorsHelp();
    else track('preview_failed', { code: error.code });
  },
});

A browser cannot tell a CORS rejection from a dead server — both surface as an opaque TypeError. The CORS message says so plainly rather than guessing which one happened.

Theming

The element reads ordinary custom properties, so it themes from your stylesheet with no API. 

file-preview {
  --fp-accent: #5b4bdb;
  --fp-radius: 16px;
  --fp-font: 'Instrument Sans', system-ui, sans-serif;
  --fp-min-height: 600px;
}

Also available: --fp-bg, --fp-bg-sunken, --fp-bg-raised, --fp-surface, --fp-border, --fp-text, --fp-text-dim, --fp-danger and --fp-mono. Dark mode follows the OS unless you set theme. For structural changes, these shadow parts are exposed: toolbar, stage, content, controls, backdrop and shell.

Custom viewers

Register your own for a format the library doesn't know, or override a built-in by reusing its id. match returns a score and the highest one wins, so you can take over a type without forking anything. 

import { registerViewer } from 'fileon';

registerViewer({
  id: 'dicom',
  label: 'DICOM',
  match: (source) => (source.ext === 'dcm' ? 1 : 0),
  load: () => import('./dicom-viewer.js'), // default export is the factory
});
// dicom-viewer.js
export default async function dicomViewer({ source, container, signal, setStatus }) {
  setStatus('Decoding…');
  const buffer = await source.arrayBuffer({ signal });
  const element = renderDicom(buffer);
  container.append(element);

  return {
    element,
    destroy: () => element.remove(),
    actions: [{ id: 'invert', label: 'Invert', run: () => element.classList.toggle('inverted') }],
  };
}
