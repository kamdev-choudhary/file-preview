fileon

One framework-free web component that previews images, PDFs, Office documents, media, code, archives and fonts — from URLs, Files, Blobs or buffers.

…or drop files anywhere on this page.

Preview any URL

Remote files stream directly where possible. If a server blocks cross-origin reads, the error explains exactly that and offers to open it in a new tab.

Sample files

Click any card to open it full-screen. Each viewer is a separate lazily-loaded chunk — open DevTools → Network to watch them arrive only when needed.

Inline mode

The same component embedded in a page instead of a modal. Switch files with the buttons; the toolbar adapts to whatever the active viewer supports.

Error handling

Every failure is typed, and the recovery buttons are chosen from the error code. These all fail on purpose.

Event log

fp-load, fp-error and fp-change events, as they fire.
