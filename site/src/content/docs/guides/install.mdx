## Without a bundler

A single module script is enough. This registers the elements and gives you a working viewer
on a static page.

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/fileon/+esm"></script>

<file-preview src="/report.pdf" bordered></file-preview>
```

## What gets downloaded

The entry is about **17 kB gzipped**. Every viewer beyond that is a separate chunk loaded on
first use, so a page that only ever previews images never downloads pdf.js, mammoth or JSZip.

<Aside type="tip" title="Check it yourself">
  Open the network panel on the [home page](/fileon/) and click through the sample files. Each
  new format pulls exactly one new chunk.
</Aside>

## Browser support

Any browser with ES modules, custom elements and shadow DOM — so current Chrome, Edge, Firefox
and Safari. There is no IE or legacy Edge support, and none is planned.
