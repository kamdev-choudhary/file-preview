---
title: Keyboard
description: Shortcuts in the modal and the inline viewer.
---

| Key                      | Action                                                        |
| ------------------------ | ------------------------------------------------------------- |
| <kbd>Esc</kbd>           | Close the modal                                                |
| <kbd>←</kbd> <kbd>→</kbd> | Previous and next file in a gallery                           |
| <kbd>Tab</kbd>           | Cycles inside the modal; focus is trapped, and restored on close |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + scroll | Zoom images and PDFs                           |

Focus is moved into the modal when it opens and returned to the element that opened it when it
closes, so keyboard and screen-reader users are never dropped at the top of the document.
